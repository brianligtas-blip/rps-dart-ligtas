# Rock, Paper, Scissors (Dart)

**Name:** Brian Ligtas
**Course/Section:** ITE 120 - ICLX3

## How to Run

1. Make sure the [Dart SDK](https://dart.dev/get-dart) is installed on your machine.
   Verify it with:
   
   dart --version
  

2. Clone this repository:
  
   git clone https://github.com/brianligtas-blip/rps-dart-ligtas.git
   cd rps-dart-ligtas
  

3. Run the program from a terminal (VS Code terminal or Command Prompt):
  
   dart rock_paper_scissors.dart
  
   > **Note:** This program reads keyboard input via`stdi`, so it must be run
   > in a terminal. DartPad does not support`stdi` input and will not work.

4. Follow the on-screen prompts:
   - Enter Player 1's and Player 2's names.
   - Player 1 enters a move (rock/paper/scissors), then the screen clears.
   - Player 2 enters a move.
   - The round result and current score are displayed.
   - Type`` to play another round, or`` to end the game and see the final score.
